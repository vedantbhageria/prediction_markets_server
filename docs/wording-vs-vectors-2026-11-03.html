Wording is better at

"Who will win" markets with a named outcome. Grenell, Oprah, Byron Donalds, Shakhtar, LA Rams: wording finds the same name; vectors find the right event but another candidate, because the name is masked out of the vector and not yet put back into the ranking.
Exact siblings on the same venue (ladders, same phrasing).

Fix that would make vectors win on both: count the named outcome in the distance (same name first, with prefix matching so Kalshi's "Los Angeles R" meets "Los Angeles Rams").
